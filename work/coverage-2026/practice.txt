q1 IPv4 주소를 알고 있을 때 같은 링크에 있는 장비의 MAC 주소를 찾는 프로토콜은?
답: ARP
ARP는 IPv4 주소를 MAC 주소에 대응시킵니다. DNS는 이름 해석입니다.

q2 DNS에서 IP 주소로 도메인 이름을 찾는 역방향 조회 레코드는?
답: PTR
PTR은 IP → 이름입니다. A는 이름 → IPv4 주소입니다.

q3 IPv6 주소를 이름에 대응시키는 DNS 레코드는?
답: AAAA
AAAA는 IPv6 주소입니다. A는 IPv4 주소입니다.

q4 기존 도메인 이름의 별칭을 지정하는 DNS 레코드는?
답: CNAME
CNAME은 별칭을 다른 도메인 이름에 연결합니다.

q5 도메인의 메일 교환 서버를 지정하는 DNS 레코드는?
답: MX
MX는 메일 교환 서버를 지정합니다. 메일 송신 프로토콜 SMTP와 구별하세요.

q6 DNS 영역의 일련번호와 갱신 주기 등이 들어 있는 레코드는?
답: SOA
SOA에는 Serial, Refresh, Retry, Expire 등의 영역 관리 정보가 있습니다.

q7 DNS의 기본 포트와 대표적인 전송 프로토콜 조합은?
답: 53, UDP와 TCP
DNS는 UDP와 TCP를 모두 사용합니다. 일반 질의는 주로 UDP, 영역 전송은 TCP를 사용합니다.

q8 DHCPv4 서버와 클라이언트가 사용하는 UDP 포트 순서는?
답: 67, 68
서버가 67, 클라이언트가 68입니다.

q9 SSH 원격 접속의 기본 포트는?
답: 22
SSH는 기본 TCP 22입니다. Telnet은 TCP 23입니다.

q10 전통적인 HTTPS 서비스의 기본 포트는?
답: 443
HTTPS의 기본 포트는 443입니다. HTTP/3는 UDP 443을 이용할 수 있습니다.

q11 SMTP 서버 간 메일 전달의 기본 포트는?
답: 25
SMTP는 25, POP3는 110, IMAP은 143을 먼저 연결하세요.

q12 SNMP 조회와 Trap에 주로 사용하는 UDP 포트 순서는?
답: 161, 162
SNMP 조회는 161, Trap 통지는 162입니다.

q13 다음 중 사설 IPv4 주소 대역에 속하는 것은?
답: 172.20.1.1
172.16.0.0/12는 두 번째 옥텟 16~31입니다.

q14 127.0.0.1의 대표적인 용도는?
답: 루프백
자기 시스템의 IP 스택을 시험하는 루프백 주소입니다.

q15 169.254.0.0/16은 어떤 주소 범위인가?
답: IPv4 링크 로컬
APIPA와 관련된 IPv4 링크 로컬 범위입니다. 사설 3대 대역과 구별합니다.

q16 일반 IPv4 LAN에서 /27 서브넷 하나의 사용 가능한 호스트 수는?
답: 30
호스트 비트는 5개입니다. 2^5−2=30개입니다.

q17 192.168.10.77/27이 속한 네트워크 주소는?
답: 192.168.10.64
블록 크기는 32입니다. 77은 64~95 블록에 포함됩니다.

q18 192.168.10.77/27이 속한 서브넷의 브로드캐스트 주소는?
답: 192.168.10.95
64~95 블록의 마지막 주소 .95가 브로드캐스트입니다.

q19 /24 네트워크를 /26으로 나눌 때 만들어지는 서브넷 수는? (subnet zero 포함)
답: 4
네트워크 비트 2개를 더 사용하므로 2^2=4개입니다.

q20 호스트 5개를 수용하는 일반 LAN의 가장 작은 서브넷은?
답: /29
/29는 사용 가능 6개입니다. /30의 2개로는 부족합니다.

q21 -rwxr-x--x의 숫자 권한 표기는?
답: 751
소유자 7, 그룹 5, 기타 1입니다. 첫 문자는 파일 유형입니다.

q22 기존 읽기·실행 권한을 유지하면서 모든 사용자에게 쓰기 권한만 추가하려면?
답: chmod a+w sample
a+w는 추가입니다. 222와 a=w는 기존 읽기·실행 권한을 보존하지 않습니다.

q23 소유자·그룹 권한은 그대로 두고 기타 사용자 권한만 읽기로 지정하려면?
답: chmod o=r sample
o=r은 기타 사용자 권한을 읽기만 가능하게 지정합니다.

q24 TCP 3-way handshake의 올바른 순서는?
답: SYN → SYN+ACK → ACK
클라이언트 SYN, 서버 SYN+ACK, 클라이언트 ACK 순서입니다.

q25 서버가 LISTEN 상태에서 SYN을 받고 SYN+ACK을 보낸 뒤의 상태는?
답: SYN-RECEIVED
서버는 SYN-RECEIVED 상태가 되고 마지막 ACK 수신 후 ESTABLISHED로 진행합니다.

q26 TCP 연결의 정상 종료 요청에 사용하는 플래그는?
답: FIN
FIN은 정상 종료 요청, RST는 연결 초기화 등에 사용합니다.

q27 UDP 헤더에 포함되지 않는 필드는?
답: 순서 번호
UDP 헤더는 출발지 포트·목적지 포트·길이·체크섬으로 구성됩니다.

q28 UDP에 대한 설명 중 옳지 않은 것은?
답: 프로토콜 자체가 순서를 보장한다
UDP는 자체 전달·순서 보장이 없습니다. 오류 검출 필드와 신뢰성 보장은 별개입니다.

q29 IPv4 TTL에 대응하는 IPv6 기본 헤더 필드는?
답: Hop Limit
IPv6는 Hop Limit으로 홉 제한을 나타냅니다.

q30 IPv6 주소 축약의 올바른 규칙은?
답: ::는 한 주소에서 한 번만 사용한다
여러 ::를 쓰면 생략된 블록 수를 명확히 복원할 수 없습니다.

q31 IPv4 멀티캐스트 그룹의 가입·탈퇴를 관리하는 프로토콜은?
답: IGMP
IPv4 그룹 관리는 IGMP입니다. IPv6는 MLD와 연결합니다.

q32 ICMPv4 Echo Request의 Type 번호는?
답: 8
요청은 8, 응답은 0입니다. Type 11은 Time Exceeded입니다.

q33 OSI 데이터링크 계층의 대표 데이터 단위는?
답: 프레임
물리는 비트, 데이터링크는 프레임, 네트워크는 패킷입니다.

q34 신호를 재생해 전달하는 리피터가 동작하는 OSI 계층은?
답: 물리
리피터와 허브는 대표적인 L1 장비입니다.

q35 L2 스위치가 프레임 전달 시 주로 확인하는 목적지 주소는?
답: MAC 주소
L2는 MAC, L3는 IP, L4는 포트와 연결해 외우세요.

q36 하나의 스위치에서 논리적인 브로드캐스트 도메인을 나누는 기술은?
답: VLAN
VLAN은 논리 분리, STP는 L2 루프 방지입니다.

q37 스위치의 이중 경로에서 루프를 방지하는 프로토콜은?
답: STP
STP는 일부 경로를 차단하여 L2 루프를 막습니다.

q38 스위치 사이 VLAN 태그 전달의 대표 규격은?
답: 802.1Q
802.1Q는 VLAN 태깅, 802.1X는 포트 기반 접근 인증입니다.

q39 제어 평면과 데이터 평면을 분리하고 컨트롤러로 제어하는 기술은?
답: SDN
SDN의 단서는 평면 분리·프로그래밍 가능한 제어입니다.

q40 네트워크 장비 기능을 범용 서버의 가상 소프트웨어 기능으로 구현하는 것은?
답: NFV
NFV는 네트워크 기능 가상화입니다. SDN과 단서를 구별합니다.

q41 동일한 데이터를 두 디스크에 복제하는 대표 RAID는?
답: RAID 1
미러링은 RAID 1입니다. RAID 0은 중복성 없는 스트라이핑입니다.

q42 분산 패리티를 사용하고 디스크 1개 장애를 허용하는 RAID는?
답: RAID 5
RAID 5는 최소 3개 디스크와 분산 패리티를 사용합니다.

q43 2TB 디스크 4개로 RAID 5를 구성한 전형적인 사용 용량은?
답: 6TB
(N−1)×D=(4−1)×2=6TB입니다. 파일시스템 등 부가 오버헤드는 제외합니다.

q44 서버에 요청을 순차적으로 돌아가며 배분하는 방식은?
답: Round Robin
순번은 Round Robin, 연결 수가 가장 적은 서버는 Least Connections입니다.

q45 URL이나 쿠키를 기준으로 분산하는 장비의 대표 분류는?
답: L7 스위치
응용 내용은 L7 단서입니다. 암호화된 내용은 TLS 처리 조건을 고려합니다.

q46 Windows에서 DNS 클라이언트 캐시를 지우는 명령은?
답: ipconfig /flushdns
flushdns는 DNS 클라이언트 캐시 삭제, renew는 DHCP 갱신입니다.

q47 Windows netstat에서 연결의 PID를 표시하는 옵션은?
답: -o
-o는 PID, -b는 관련 실행 파일, -r은 라우팅 테이블입니다.

q48 Windows에서 중단할 때까지 ping을 반복하는 옵션은?
답: -t
Windows의 -t는 계속 반복입니다. Linux의 옵션과 혼동하지 마세요.

q49 Linux 프로세스와 자원 상태를 실시간 갱신하는 대표 명령은?
답: top
top은 실시간 모니터링, ps는 순간적인 프로세스 목록입니다.

q50 Linux 로그인 실패 기록을 확인하는 전통적 명령은?
답: lastb
lastb는 btmp의 실패 기록, last는 성공 로그인 이력입니다.

q51 서비스를 지금 실행하지 않고 부팅 자동 시작을 설정하는 명령은?
답: systemctl enable httpd
enable과 start는 다릅니다. enable --now는 둘 다 수행합니다.

q52 사용자 자신의 crontab 전체를 삭제하는 옵션은?
답: -r
-l 조회, -e 편집, -r 삭제입니다.

q53 vi에서 변경 내용을 저장하지 않고 종료하는 명령은?
답: :q!
:q!는 저장 없이 종료합니다. :q는 변경이 있으면 거부될 수 있습니다.

q54 /etc/passwd의 암호 필드 x의 의미는?
답: 일반적으로 shadow에 해시가 있음
x는 shadow 사용의 표시이며 비밀번호 자체가 아닙니다.

q55 일반 사용자 홈 디렉터리의 일반적인 위치는?
답: /home/사용자
/usr는 명령·라이브러리 등입니다. root의 홈은 보통 /root입니다.

q56 Apache 웹 서버의 수신 포트를 8081로 지정하는 지시자는?
답: Listen 8081
포트는 Listen, 본문 크기는 LimitRequestBody, 기본 문서는 DirectoryIndex입니다.

q57 RIP의 메트릭과 최대 유효 값의 올바른 조합은?
답: 홉 수, 15
RIP는 홉 수이며 15까지 유효, 16은 도달 불가입니다.

q58 Link State 방식이며 SPF·Dijkstra 알고리즘과 관련된 프로토콜은?
답: OSPF
OSPF는 Link State, RIP는 Distance Vector, BGP는 Path Vector입니다.

q59 AS_PATH와 정책에 기반한 AS 간 라우팅의 대표 프로토콜은?
답: BGP
BGP는 AS 간 정책 라우팅의 대표이며 TCP 179를 사용합니다.

q60 오류가 발생한 프레임만 선택해 재전송하는 방식은?
답: Selective Repeat
Selective Repeat는 오류 프레임만, Go-Back-N은 오류 프레임부터 이후까지 재전송합니다.

q61 데이터가 없어도 고정된 타임 슬롯을 할당하는 방식은?
답: 동기식 TDM
동기식 TDM은 고정 슬롯 때문에 유휴 대역폭이 낭비될 수 있습니다.

q62 무선 LAN에서 채널을 살피고 백오프하여 충돌을 회피하는 방식은?
답: CSMA/CA
무선은 CSMA/CA, 전통적 공유 이더넷은 CSMA/CD입니다.

q63 DHCPv4 초기 임대 메시지의 올바른 순서는?
답: Discover → Offer → Request → ACK
DORA: Discover, Offer, Request, ACK 순서입니다.

q64 FTP 수동 모드 데이터 연결의 시작 방향은?
답: 클라이언트가 서버가 알린 포트로 시작
수동 모드는 클라이언트가 서버의 데이터 포트로 연결을 시작합니다.

q65 IIS 웹 사이트의 실제 파일 경로에 대한 올바른 설명은?
답: 관리자가 다른 물리 경로로 설정할 수 있다
기본 경로는 변경 가능합니다. 바인딩과 실제 파일 경로를 구별합니다.

q66 AD 도메인 안에서 부서별 관리 단위를 구성할 때 사용하는 것은?
답: OU
OU는 조직 구성 단위입니다. 도메인 자체와 구별합니다.

q67 L2TP에 대한 설명으로 올바른 것은?
답: 기밀성 보호를 위해 IPsec 등과 결합할 수 있다
L2TP 터널링과 암호화는 별개입니다. L2TP/IPsec 조합을 구별하세요.

q68 클라우드 배포 모델에 해당하지 않는 표현은?
답: On-premises
대표 배포 모델은 Public, Private, Community, Hybrid입니다. On-premises는 설치·운영 위치 표현입니다.

q69 DNSSEC의 주된 역할은?
답: DNS 데이터 출처와 무결성 검증
DNSSEC는 인증·무결성을 검증합니다. 기밀성 제공과 구별합니다.

q70 광케이블의 코어와 클래딩에서 전반사가 가능한 조건은?
답: 코어 굴절률이 더 높고 임계각을 초과
높은 굴절률의 코어에서 낮은 클래딩으로 향하는 경계에서 임계각을 넘으면 전반사가 일어납니다.

q71 중앙 장비 하나에 단말을 각각 연결한 Star 구성의 특징은?
답: 중앙 장비 장애가 전체 통신에 영향을 줄 수 있다
단말 자체 장애와 중앙 장비 장애의 영향 범위를 구별하세요.

q72 Linux에서 파일시스템의 여유 공간을 확인하는 대표 명령은?
답: df -h
df는 파일시스템 공간, du는 파일·디렉터리 사용량, free는 메모리입니다.
