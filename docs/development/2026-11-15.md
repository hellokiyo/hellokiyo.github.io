### 선정 목적과 선택 이유

코드 기반 HTML/CSS 도식을 선택했다. 이미지 생성/외부 이미지 다운로드 없이 글자 확대·테마·휴대폰 줄바꿈과 텍스트 접근성을 유지할 수 있다. 사진/정밀 장비 도면이 필요한 경우 실제 이미지가 더 적합하지만 이번에는 단계·비교·계층을 표현한다. 원래 생성 학습 데이터는 그대로 두고 UI 모듈에서 보조 설명만 연결했다. 어려운 표현은 짧은 비유와 ‘꼭 기억해요’로 풀되 원래 본문의 예외/검토 상태를 숨기지 않는다.

### 구현 결과

- ui/theory-visuals.js와 css/theory-visuals.css: 12단원에 개념 카드·화살표·OSI 계층·서브넷64칸·권한/재전송 비교·복습/시험 흐름. 일부 단원 자기 확인과 본문 바로가기.
- reference-pages.js: 모바일 목차 기본 접힘. app.js는 data-scroll-target을 본문 내부 스크롤/포커스로 처리해 경로 이동과 구분한다.
- pages/user-guide-page.js: #help의 ‘1분 사용법’. 홈·설정·도우미 검색에서 접근하고 5분 학습으로 바로 시작한다. 설명서 다운로드도 제공한다.
- [짧은 설명서](../guides/quick-start.md): 문제 선택→답/이유→오답 복습을 어린 사용자도 따라갈 수 있도록 쉬운 말로 작성했다. 어린이 대상 실제 사용성 시험을 한 것은 아니다.
- 5분 학습의 12분 시간 배분 문구 혼동, 도우미 추천의 배열 순서 의존, 모바일 중첩 여백, 어두운 테마의 고정 문단/링크 색 문제를 수정했다.
- index와 서비스 워커에 새 자산·설명서를 포함하고 v23으로 갱신했다. 기존 ID·점수·학습 저장 계약을 바꾸지 않았다. AI·로그인·키·새 저장소는 추가하지 않았다.

### 실제 검증과 한계

- node scripts/check-site.cjs: 최종 로그 참조. 기존92개 테스트와 index자산49개·하위JS구문·CSS참조·캐시 목록 검사.
- 데스크톱1440×900과 모바일390×844에서 11개 화면을 순회했다. 12개 이론 단원도 각각 확인해 그림 누락/페이지 가로 넘침 없음. 320×640, 768×1024, 844×390에서는 대표 그림3단원과 사용법을 추가 확인했다.
- 실제 조작: 사용법→5분 시작, 답/평가→오답노트, 키워드/명령 검색·펼침, 계산 정상/오류, 기출2022필터·연습 제출/채점, 계획 체크, 직접 만든 TXT 저장/검색/미리보기, 게임 일시정지/종료/목록, 사용법 검색, 설정→사용법 이동과 닫힘, 테마 변경/원복.
- 브라우저 오류 로그0개. 감사 JSON과 screenshots는 audits/visual-guide-browser-2026-11-15.json, theory-visual-desktop.jpg, quick-start-mobile.jpg다. 상세 [점검 보고서](../review-2026-11-15.md)에 화면별 관찰과 미검증 항목을 분리했다.
- 실제 iPhone/Galaxy·초보/어린이 과제 시험, 설치 앱의 업데이트/강제 오프라인, 원본 파일 드래그, 긴 타이머 실제 경과, 모든 문제의 정답 검수는 수행하지 않았다. 기존92개 자동 회귀 검사와 브라우저 직접 조작을 같은 의미로 쓰지 않는다.

### 승인과 학습

로컬 전용 서버 실행/재시작만 실제 권한 확대 실행 도구를 사용했다. [당일 실행 로그](approvals-2026-11-15.md)에 기록했다. 기존 학습 기록을 삭제하지 않았고 합성 점검은 별도 로컬 주소에서 수행했다. Git·배포는 하지 않았다.

학습 포인트는 CSS 로딩 순서와 명시도, 문서 내부 링크와 앱 라우팅의 구분, 시각 설명과 원본 데이터 책임 분리다. 짧은 연습: 블랙 테마에서 서브넷 그림/본문 링크를 읽고, ‘본문으로’를 눌러 URL이 단원 경로 그대로인지 확인한다. 자세한 구조는 [아키텍처](../architecture.md)에 반영했다.
