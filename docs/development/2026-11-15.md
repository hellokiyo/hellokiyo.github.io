### 선정 목적과 선택 이유

코드 기반 HTML/CSS 도식을 선택했다. 이미지 생성/외부 이미지 다운로드 없이 글자 확대·테마·휴대폰 줄바꿈과 텍스트 접근성을 유지할 수 있다. 사진/정밀 장비 도면이 필요한 경우 실제 이미지가 더 적합하지만 이번에는 단계·비교·계층을 표현한다. 원래 생성 학습 데이터는 그대로 두고 UI 모듈에서 보조 설명만 연결했다. 어려운 표현은 짧은 비유와 ‘꼭 기억해요’로 풀되 원래 본문의 예외/검토 상태를 숨기지 않는다.

- 실제 iPhone/Galaxy·초보/어린이 과제 시험, 설치 앱의 업데이트/강제 오프라인, 원본 파일 드래그, 긴 타이머 실제 경과, 모든 문제의 정답 검수는 수행하지 않았다. 기존92개 자동 회귀 검사와 브라우저 직접 조작을 같은 의미로 쓰지 않는다.

### 승인과 학습

로컬 전용 서버 실행/재시작만 실제 권한 확대 실행 도구를 사용했다. [당일 실행 로그](approvals-2026-11-15.md)에 기록했다. 기존 학습 기록을 삭제하지 않았고 합성 점검은 별도 로컬 주소에서 수행했다. Git·배포는 하지 않았다.

학습 포인트는 CSS 로딩 순서와 명시도, 문서 내부 링크와 앱 라우팅의 구분, 시각 설명과 원본 데이터 책임 분리다. 짧은 연습: 블랙 테마에서 서브넷 그림/본문 링크를 읽고, ‘본문으로’를 눌러 URL이 단원 경로 그대로인지 확인한다. 자세한 구조는 [아키텍처](../architecture.md)에 반영했다.

- 검증과 한계: 제공 문서 읽기와 현행 정적 구조 대조만 수행. 공식 일정·자격정보·문제 이용권 검증 완료를 의미하지 않는다.

## 자격증별 문제 자료·출처와 확장 구조 조사

- 질문 원문(선택 응답): “문제 추가 준비부터 — 자격증별 자료·출처와 기존 구조 조사”
- 요약: 구현 전 문제 확보 경로와 기존 코드의 확장 지점을 조사하도록 범위 확정.
- 의도 해석(추정): 실제 확보할 수 있는 문제와 재사용 가능한 기능을 먼저 확인해 허위 콘텐츠나 불필요한 구현을 피하려는 요구.
- 선정 목적·선택 이유: 공식기관의 게시물·출제기준·이용 안내를 우선 조사했다. 공개 여부·정답 확정·해설 검수·재배포 허용을 하나의 확인 상태로 섞지 않는다. 첫 자료 준비 후보는 같은 ICQA의 PC정비사2급 한 회차다. 이는 개발 적합성 제안이며 응시/취득 순위의 확정은 아니다.
- 조사 결과: [준비 조사 보고서](../research/exam-expansion-2026-11-15.md)에 첨부17개 후보와 보유 종목의 공식 경로·확인 상태·남은 자료를 작성했다. ICQA HWP 게시/활용 안내, KAIT 무단 이용 금지 및 허가 안내, Cisco 실제 문항 기밀 정책을 구별했다. 첨부의 전자계산기조직응용기사 명칭도 공식 개정문과 대조해 현 종목 확인 대상으로 보강했다. 공식 출제범위 게시와 첨부 전문 검토를 구분했다.
