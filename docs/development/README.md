# 개발 질문과 의사결정 기록

학습 서비스와 별도로, 질문을 어떻게 요구사항과 설계 선택으로 바꾸었는지 돌아보기 위한 개인 개발 기록이다. 앱 메뉴나 학습 콘텐츠에 연결하지 않는다.

새 요청은 해당 날짜 문서에 이어 쓴다. 질문 원문 → 요약 → 의도 해석 → 선정 목적·선택 이유 → 결과 → 검증·한계 순서로 남긴다. 의도 해석은 사실과 구별한다. 구현 전 가설과 확인된 결과도 구분한다.
