# 이론 그림·사용법·전체 화면 점검

작업 기간: 2026-11-14~15. 로컬 소스 v23. 운영 절차의 화면 순서를 따라 개발 브라우저에서 관찰했다. 실제 초보 사용자/어린이 평가나 실기기 전수 검증은 아니다.

## 반영한 개선

| 불편/관찰 | 변경 |
|---|---|
| 이론은 긴 글·표 중심이라 개념의 관계를 한눈에 보기 어려움 | 12단원에 단서 카드·화살표·계층/비교 그림과 쉬운 비유 추가. 서브넷 /26은 64칸 중 처음/마지막 주소와 호스트62칸으로 표시 |
| 휴대폰의 긴 이론 목차가 본문을 밀어냄 | 모바일에서 기본 접힘. 현재 단원을 표시하며 필요할 때 펼침 |
| 그림만 빠르게 건너뛰거나 확인하고 싶음 | 본문 바로가기와 일부 개념의 접이식 자기 확인. 원래 학습 본문 유지 |
| 모바일에서 그림 안팎의 중첩 테두리/여백으로 읽는 폭이 좁음 | 바깥 도식의 중복 테두리와 패딩을 줄임 |
| 어두운 테마에서 기존 reader의 고정 문단 색이 새 그림에도 적용됨 | 도식 CSS 로딩 위치와 테마 변수 색 적용 수정. 본문/보조 문장/본문 링크 대비 재확인 |
| 처음에 어떤 기능을 골라야 하는지 불명확 | ‘1분 사용법’ 화면과 짧은 Markdown 설명서. 홈·설정·도우미 검색에서 진입 |
| 5분 학습에도 12분 기준 시간 배분을 안내함 | 12분 세션에만 세부 시간 배분, 그 외에는 공통 학습 순서를 안내 |
| 도우미 메뉴에 항목 추가 시 기존 추천이 배열 번호에 의존 | 고정 인덱스를 목적지(#theory) 조회로 변경. 기존 검색 회귀 테스트로 확인 |

로그인·키·AI 호출·새 데이터 저장은 도입하지 않았다. 그림은 이해를 돕는 비유이며 아래 본문의 조건/예외와 함께 읽는다. 기존 문제 ID와 저장 키를 유지했다.

## 실제 화면 점검

| 순서 | 화면 | 관찰/조작 |
|---|---|---|
| 1 | 홈 | 제목·기능 진입·사용법 링크. 사용법에서 5분 시작 연결 |
| 2 | 오늘의 학습 | 5분 진입·답 선택·정답 확인·헷갈림 평가·오답노트 연결 |
| 3 | 키워드 | DHCP 검색·정답 펼침·예시 펼침 |
| 4 | 명령어 | ipconfig 검색, 결과 목록 표시 |
| 5 | 핵심정리 | 12단원 모두 그림 표시, /26 주소 그림64칸, 본문 이동 시 경로 유지/포커스 이동, 서브넷 정상 계산과 잘못된 IP 오류 |
| 6 | 문제풀이 | 2022 연도 선택→3개 확보 회차 표시, 빠른 연습·답 확인·제출 확인·채점 |
| 7 | 오답노트 | 오늘의 학습 오답1개가 해당 기능 그룹에 표시 |
| 8 | 계획 | 완료 체크 조작 |
| 9 | 자료 | 직접 만든 비개인 TXT 선택·IndexedDB 보관·검색·내용 미리보기. 원래 자료를 삭제하지 않음 |
| 10 | 산성비 | 시작·일시정지·종료·정답 목록 열기 |
| 11 | 사용법/설정/도우미 | 사용법 검색, 설정 창에서 사용법 이동 시 모달 닫힘, 테마 변경과 원복 |

11개 화면의 데스크톱/390px 모바일 순회, 12개 단원의 각 크기별 그림 존재와 가로 넘침을 확인했다. 320×640 작은 화면·768×1024 태블릿·844×390 가로 화면은 대표 그림3단원과 사용법을 추가 확인했다. 세부 결과는 audits의 브라우저 JSON을 참조한다. 결과/진행 중 세션 등은 별도 로컬 점검 주소에서 만든 합성 학습 기록이다.

## 자동 검사와 한계

`node scripts/check-site.cjs`: 기존 92개 회귀 검사, index 자산49개, 하위 JS 구문·CSS 상대 참조·서비스 워커 목록. 참고 화면 테스트도 새 그림 모듈을 로드하도록 갱신했다. 생성 데이터는 바꾸지 않았다.

기존 테스트가 다루는 파일 크기/중복/ZIP/정제/마감 등과 브라우저에서 직접 수행한 동작을 구별한다. 이번 브라우저 점검에서 원본 파일 드래그 자체·실제 설치 앱·네트워크 차단 오프라인·파일 백업 왕복·50분 실제 경과·클립보드 복사를 전부 재실행한 것은 아니다. 공식 정답과 모든 원문을 재검수한 작업도 아니다.

자유 대화 AI와 800문항의 상세 해설 부족은 이번 시각 설명 작업으로 해결된 것이 아니다. 후속 문제별 해설 작업과 분리한다. 실제 어린이/초보 사용자가 설명서를 보고 도움 없이 시작할 수 있는지는 추가 관찰이 필요하다.

## 추가 순회와 인수인계 점검 (v24)

같은 날 사용자 요청으로 다시 확인했다. 현재 판단은 **책임별 수정 위치가 정리된 구조이나, 긴 템플릿과 CSS 중첩은 남아 있다**는 것이다. 전면 재작성보다 실제 불편을 줄이는 수정과 인수인계 경로를 보강했다.

- 채점 결과의 오답 기호 `○`는 정답처럼 읽힐 수 있어 `정답 · / 오답 · / 미응답 ·`으로 구분했다. 채점 방식·정답·ID·저장 스키마는 바꾸지 않았다.
- 문제풀이와 공통 제목의 ‘오답장’을 메뉴 이름인 ‘오답노트’로 통일했다.
- 비데이터 JS 22개의 상단 책임 설명을 확인하고, 누락된 `domain/wrong-notebook.js`와 `ui/keyword-layout.js`에 상태 소유권·출처 보존·관찰자 해제 책임을 설명했다.
- [인수인계](handoff.md)에 첫 실행, 상태 전달, 요청별 수정 위치, 완료 기준과 부채를 작성했다. 루트 README와 문서 인덱스에서 연결한다. 구조 문서의 초기 CSS13개와 현재19개를 구별하고 운영 문서의 특정 과거 버전 표현도 정리했다.

수정 후 `node scripts/check-site.cjs`의 92개 검사·49개 index 참조가 통과했다. 1366×900과390×844에서 11개 화면씩 새로 순회해 제목/본문 표시와 페이지 가로 넘침을 확인했다. 콘솔 오류는 관찰되지 않았다. 결과는 `audits/handoff-browser-v24.json`이다. 기존 합성 기록이 있는 로컬4205 포트를 사용했고 사용자 공개 주소의 기록을 초기화하지 않았다.

직접 재조작한 것은 키워드 검색·정답 펼침, 공부 도우미 입력/검색/닫기/재열기 초기화, 기존 채점 결과의 오답·미응답 구분과 업데이트 후 v24 표시다. 11개 화면 순회가 모든 버튼/저장 기능의 재조작을 뜻하지 않는다. 이전 v23의 상세 조작 근거와 이번 자동 회귀 검사를 구별한다. 저장된 스크린샷은 `audits/handoff-result-v24.jpg`다.

이번에는 새 사용자 후기 조사나 실사용자 과제 시험을 하지 않았다. 문구 개선은 개발 브라우저 관찰에 따른 판단이다. 실제 기기·전체 백업 복원·완전 오프라인·50분 실제 경과·기출 정답 전수 대조는 재검증하지 않았다. 우선 남은 작업은 상세 해설 보강, 실제 초보자의 회차 선택/오답 복습 관찰, 긴 템플릿과 CSS를 변경 단위로 정리하는 것이다.
