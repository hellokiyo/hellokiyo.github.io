# 맞춤 연습·북마크·같은 문제 반복 · v30

## 사용법

1. 문제풀이에서 **내게 맞춰 풀기**를 찾는다. 풀던 문제가 있으면 **문제 선택으로**를 눌러도 답안은 유지된다.
2. 문제 범위·단원·학습 상태·문제 수를 고른다. 검색어와 순서 섞기도 선택할 수 있다.
3. 조건에 맞는 개수가 표시된다.0개면 시작 버튼은 꺼지고 범위를 넓히라는 안내가 나온다. 요구한 수보다 적으면 가능한 문제만 중복 없이 선택한다.
4. 문제의 **☆ 이 문제 북마크**를 누른다. 문제 선택으로 돌아가 **학습 상태 → 북마크만**을 고르면 저장한 문제만 풀 수 있다.
5. 제출 후 **이 문제들 다시 풀기**는 같은 문항 ID·순서로 시작하며 이전 답안/정답 공개는 초기화한다. 기출 회차의 기존 반복 버튼도 유지한다.

로그인·회원가입·계정·인증 서버는 없다. 사용자가 명시적으로 변경을 요청하기 전까지 추가하지 않는 원칙을 AGENTS.md에 기록했다. 학습 기록은 현재 브라우저의 시험별 저장소에 있으며 자동 서버 업로드나 동기화를 추가하지 않았다.

## 기능의 의미

- 검색은 문제와 보기에서 수행하며 출처/단원/상태를 교집합으로 적용한다.
- 미학습·미채점은 해당 문제 ID의 실제 ReviewCore.studyCount가0인 항목이다. 키워드 카드와 원문 문제는 다른ID이므로 같은 개념이라는 이유로 임의 합치지 않는다.
- 오답 필터는 채점 가능한 문제ID만 골라 기존 오답노트와 연결한다. 키워드형 오답은 기존 오답노트/오늘의 학습에서 복습한다.
- 수록된 기출/자체 연습은 기존 데이터 기준이다. 새 외부 원문을 수집/자동 변환한 기능이 아니다.
- 북마크는 문제의 중요 표시이며 정답/암기 완료/오답 상태를 바꾸지 않는다. 노출 빈도나 시험 중요도를 뜻하지 않는다.

## 책임과 호환

`StudyCore.selectPractice`가 순수 필터/중복제거/문항수 제한을 담당하고 `QuizPage`가 입력·미리보기·시작·북마크·반복을 연결한다. 조립부는 이벤트를 전달한다. 기존 CSS assessment와 테마 변수를 재사용한다.

상태의 `bookmarks`는 선택 시험의 알려진 문제ID만 남기며 기존 백업은 빈 배열로 호환된다. 학습JSON에 포함되며 다른 시험의 백업은 기존 시험 식별 검사로 거부한다. 세션과 최근 기록의 `practiceKind`는 quick 모드의 custom/repeat만 허용한다. 선택 화면의 임시 필터는 백업하지 않는다. 구버전 앱은 새 필드를 무시할 수 있으므로 원본 JSON을 보관한다.

문제 선택 화면은 `#quiz/setup`이다. 시작/이어가기는 `#quiz`로 돌아가 새로고침 뒤 세션을 복원한다. 진행 중 연습을 다른 구성으로 바꿀 때에는 기존 답안을 채점하지 않는다는 확인을 받는다.

## 참고와 선택 이유

[모두CBT 참고 화면](https://www.moducbt.com/category/%EC%82%B0%EC%97%85%EC%95%88%EC%A0%84%EC%82%B0%EC%97%85%EA%B8%B0%EC%82%AC%EC%8B%A4%EA%B8%B0(%ED%95%84%EB%8B%B5%ED%98%95)-%EA%B8%B0%EC%B6%9C-%EA%B3%BC%EB%85%84%EB%8F%84-%EC%95%94%EA%B8%B0%EC%9E%A5)의 맞춤 시작·북마크·랜덤 학습과 기록 접근을 웹 도구로 확인했다. 기존 서비스에 검색/오답/기억평가가 이미 있으므로 별도 비슷한 메뉴를 또 만들지 않고 문제풀이 진입에 선택 기능을 통합했다. 외부 문제/답안/코드/화면 문구를 그대로 복제하지 않았다.

리뷰 평점이 보이는 것과 실제 후기 조사·사용자 과제 검증은 다르다. 이번에는 후기 본문을 분석하지 않았고 개발 브라우저에서 직접 조작해 확인한다. 타사 전체 기능이나 유료 플랜을 재현했다는 뜻도 아니다.
