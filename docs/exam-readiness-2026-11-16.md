# 시험별 실제 수록량과 기능 완성도 보고 · 2026-11-16

## 결론

네트워크관리사2급만 실제 회차 기출을 풀 수 있다. 나머지16시험은 공통 기능에 자체 기초 문제20~30개를 연결한 상태다. 기능의 동작과 시험 대비 콘텐츠의 충분함을 구별해야 한다.

데이터 출처는 현재 앱이 읽는 study-data/questions/latest-paper/past-papers 및 ExamPractice.get 결과다. 공개 호스트를 새로 확인한 결과가 아니라 로컬 프로젝트v30 기준이다. 이번 요청에서는 앱을 수정하지 않고 실제 데이터를 다시 집계했다.

## 3. 중복을 빼면 어느 정도인가

다른16시험의 자체 문제는 시험별ID로340개이지만 질문+정답내용+해설로 중복 제거하면110개다. 보기 순서와 시험ID만 다르다고 별도 내용으로 세지 않았다. 키워드/문제예시도 같은 기초 개념을 재사용하므로20문제+20키워드=40개의 서로 다른 개념이라는 뜻이 아니다.

다음 쌍은 내용20개 전체가 같다. 순서나ID는 다를 수 있다.

- PC정비사 2급 ↔ PC Master(정비사) (20개)
- 정보처리기사 ↔ 정보처리산업기사 (20개)
- 정보기기운용기능사 ↔ CCNA (20개)
- 정보보안기사 ↔ 인터넷보안전문가 2급 (20개)
- 공간정보융합기능사 ↔ 측량및지형공간정보기사 (20개)

개념 재사용 자체는 가능하지만 현재는 자격별 깊이/사례/과목 설계가 충분하지 않다는 뜻이다. 두 자격을 선택했다고 서로 다른 대비 문제집을 제공하는 수준은 아니다.

## 5. 우선 개선 판단

1. 네트워크 기존800문항의 상세 해설과 최신4회 정답 검수부터 보완한다. 지금 가장 많은 학습자가 반복 활용할 수 있는 콘텐츠의 이해 품질 문제다.
2. 다른 시험은 공식 출제기준과 자료를 매핑해 자격별 범위와 난도를 먼저 구분한다. 동일20문항의 시험 이름만 다른 상태를 콘텐츠 확장 완료라고 표시하지 않는다.
3. 기출 수록은 원문 확보→이용 조건 확인→문제/보기/정답/그림 검수→회차 데이터 생성→학습 동작 확인 순서로 진행한다. 출처 링크만 추가하는 것과 다르다.
4. 과목별 분석·공식 시험 규칙·시험 전용 도식/계산/실습을 시험별로 보완한다. 공통 메뉴를 더 늘리는 것은 현재 최우선 과제가 아니다.

이 우선순위는 현재 코드/데이터의 부족을 바탕으로 한 개발 판단이다. 모든 자격의 최신 공식 출제기준을 새로 대조한 시험학적 평가나 실제 사용자 연구 결과가 아니다.
