# 문제 위치 복구와 정적 화면 잠금

> 같은 날 후속 요청으로 고정 SHA-256비교를 제거하고 한국 날짜 자동 계산으로 변경했다. 아래 고정해시 설명은 최초v33선택이며 현행운영은 [설정](../settings.md)과 개발일지의v34를 따른다. 날짜는 비밀이 아니므로 해시구현을 유지할 이유가 없어 삭제했다.

## 읽는 위치와 정답 저장은 별개

`pages/wrong-notebook-page.js`는 복습을 시작할 때 출처+문항 목록을 고정한다. 정답 처리로 저장된 오답 목록을 줄이더라도 현재 문제를 즉시 지우지 않는다. 다음 버튼을 누를 때 읽는 위치를 바꾼다. `getState()`로 최신 오답 상태를 읽되 현재 복습 목록의 수명은 화면에 둔다.

`ui/page-ui.js`의 focusQuestion은 재렌더링으로 버튼이 사라진 뒤 키보드 포커스를 새 문제로 복구한다. preventScroll로 예상치 못한 자동 스크롤을 먼저 막고 문제 시작을 정렬한다. CSS scroll-margin-top은 상단바 아래 공간을 확보한다. 다른 복잡한 페이지에서는 요소 위치/스크롤 보존 또는 sticky영역이 유리할 수 있지만, 이번 요구는 다음문제 시작으로 일관되게 이동하는 것이다.

연습: 긴 지문에서 아래로 내려 다음을 누른 뒤 포커스가 번호판이 아니라 문제에 있는지, 다른 출처에 남은 같은 오답이 유지되는지 확인한다.

## 화면 잠금은 서버 인증이 아니다

`platform/screen-lock.js`는 코드를 SHA-256으로 비교하고 탭의 sessionStorage에 통과 표시만 저장한다. 기존 학습localStorage와 분리하여 다시 잠가도 진도는 보존한다. CSS는 잠긴 동안 공부 화면을 가린다. HTTP LAN에는 WebCrypto가 없을 수 있어 ASCII숫자코드 SHA-256을 독립적으로 구현하고 Node crypto 표준값과 검증했다.

해시를 사용해도 짧은 숫자코드의 후보공간은 작으며 이JS/파일은 그대로 공개된다. 정적파일에 들어 있는 검사 코드는 요청 자체를 거절할 수 없다. 타인의 접근을 실제로 차단하려면 파일을 전달하기 전 호스팅/서버에서 권한을 검사해야 한다. 이번사용자요청의 ‘아주간단한가림막’을 서버인증 완성으로 표현하지 않는다.

연습: 화면잠금통과표시·학습기록·문제원본 세 대상 중 무엇이 탭에, 무엇이 브라우저에, 무엇이 공개파일에 있는지 설명한다. 검사수단 변경과 실제정보보호의 차이를 확인하는 연습이며 우회 구현을 뜻하지 않는다.
