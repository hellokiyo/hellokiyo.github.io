# 시험별 화면 비교·수정 결과 · v29

기준은 네트워크관리사2급의 현재 화면과 실제 학습 동작이다. 후기 기반 사용자 연구나 실기기 검증과는 구별한다. 로컬 정적 앱에서 확인했으며 Git/게시를 하지 않았다.

## 발견한 차이와 조치

| 항목 | 확장 시험에서 발견한 차이 | 수정 |
|---|---|---|
| 홈 | 별도 간소화 렌더러 때문에 시험일·이어가기·복습 현황·목표·사용법 누락 | 공통 홈으로 통합, 제목·보유 자료·기출 CTA만 시험별 주입 |
| 카드 | 색/아이콘/위계가 없는 동일 카드8개 | 기존 홈4개 주 학습 카드와 보조 자료 목록 재사용 |
| 키워드 | 문자열 ID의 숫자 변환으로 NaN 카드 번호 | 데이터의 원래 순서로 번호 표시, 검색 후에도 유지 |
| 검색 | 다른 시험에서도 ARP 같은 네트워크 예시 고정 | 선택 시험의 용어를 검색 예시로 사용 |
| 가이드 | 다른 시험에도 네트워크 내려받기 링크 노출 | 공통 hidden 규칙으로 의미 보장, 수록 시험에만 표시 |
| 사용법 | 다른 시험은 단순 목록만 제공 | 공통3단계·FAQ·5분 시작·설정/백업 안내로 통합 |

| 자료실 | 이미 연습 가능한데 ‘사이트 내 문제풀이 준비 중’ 표시 | 실제 회차 대기와 자체 기초 연습을 구별하고 문제풀이 버튼 제공 |

## 공통으로 확인할 동작

시험별 저장 키와 기존 문제 ID는 유지한다. 홈/설정/문제풀이/오늘의 학습/키워드/산성비/오답/핵심정리/노트/계획/파일 보관은 공통 모듈로 작동한다. 시간 제한 기초 연습은 공식 시험 시간이나 채점 규칙을 흉내 낸 모의시험이 아니다.

추천은 이용 시간의 비율에 따른 서비스 제안이며 학습 효과·점수·피로도를 측정하지 않는다. 확장 시험에서 네트워크2026년의22%/88점 근거를 표시하지 않는다. 시험별 추천 저장소는 학습 JSON 백업 범위에 포함되지 않는다.

## 남는 콘텐츠 차이

| 구분 | 네트워크관리사2급 | 다른16시험 |
|---|---|---|
| 풀 수 있는 문제 | 기존922문항(자체72+기출850) | 자체 기초20~30문항씩, 총340개 시험별ID |
| 회차 기출 |17회차 | 출처 목록만 조사, 사이트 내 실제 기출 수록 미완료 |
| 이론 |12단원과 그림·계산기 |2~3분야의 기초 설명, 전 범위와 그림 자료 부족 |
| 시험 규칙 |서비스50문제/50분 연습과회차 반복 |서비스20/30분 기초 연습. 시험별 과락·단계·실기 미구현 |
| 검수 |4회차 공식 정답 대조 등 일부 미완료 |자체 개념·보기/해설 구조 검사. 전문가/공식 전 범위 검수 미완료 |

UI와 저장 동작을 맞춘 것이 콘텐츠 동등성을 뜻하지 않는다. 실제 기출 확장은 원문 확보→출처/권리 확인→정답/보기/그림 검수→별도 회차 어댑터→풀이 회귀 확인을 거쳐야 한다.

## 검증

- 자동: `node scripts/check-site.cjs`107개 테스트·정적참조56개·JS구문 통과. 추가 회귀는 확장 홈의 이어가기/목표/수량, 계획 단원 경로/완료, 날짜별 연습 시간, 문자열ID의 카드 번호/검색, 네트워크 전용 근거 제외를 확인한다.
- 데이터: 기존 네트워크922문항의 순서별 ID/정답 SHA256이 기준과 일치.
- 화면:17시험×11화면×3크기(1366×900,390×844,820×1180)=561회. 빈 본문·좌우 넘침·NaN 표기 없음. 최종 콘솔 오류 없음.
- 공통 홈:17개 모두 시험일/배너/복습현황/주학습카드4개/목표3개/추천1개 확인. 네트워크 전용 내려받기와 숫자 근거표는 네트워크에만 표시.
- 직접 조작: 새16시험 각각 답 선택→새로고침 복원(선택1개), 5분복습→답선택→해설→모름→오늘의 학습 오답1개 저장, 키워드정답/예시열기/암기체크 전환, 단원읽음 전환, 산성비시작→모름→종료→산성비 오답1개 저장. 암기/읽음 전환은 검사 전 상태로 되돌렸다.
- 증거: 아래JSON, [데스크톱](../audits/exam-parity-v29-desktop.jpg), [모바일](../audits/exam-parity-v29-preview.jpg). 전체 세로 캡처도 audits/exam-parity-v29-mobile.jpg에 있다.
- 제한: 개발 브라우저 viewport 검사다. 실제 아이폰/갤럭시/설치앱·오프라인·공식 정답/기출 검수를 수행한 것이 아니다. 이번 순회는 모든 시험의 파일 드롭/ZIP·백업 복원·공식시간 만료까지 전수 조작하지 않았다(해당 공통 동작은 기존 자동검사로 확인). 이용 시간 추천의 시간 경과 분기는 자동검사로 검증했고 실제로10분 이상 대기하지 않았다. localhost:4205의 직접 조작에는 합성 학습/오답 기록이 남아 있다. 공개 서비스의 기록에는 접속하지 않았다.
