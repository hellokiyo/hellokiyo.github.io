# 다른 자격시험 문제 추가 준비 조사

## 2026-11-16 추가 확인: 사용자가 자료를 찾아야 하는지

자료 탐색은 개발 작업에서 직접 수행할 수 있다. 공식기관과 CBT 자료실의 게시물·첨부 경로를 먼저 확인하고 접근이 막힌 자료만 별도로 구분한다. 예를 들어 [ICQA PC정비사2026년4회](https://www.icqa.or.kr/cn/board/dataroom/264)는 공식 HWP 게시물이고, [COMCBT PC정비사2024년3회](https://www.comcbt.com/xe/je/8133859)는 교사용/학생용 HWP·PDF 첨부가 있는 게시물로 확인했다. 문제지·정답·제3자 해설의 확보와 공개 서비스 수록 가능 여부는 별도 검수한다. 이번 추가 확인에서는 파일을 수집/파싱하거나 문제은행에 반영하지 않았다.

로그인·접근 제한이나 사용자만 보유한 원본이 필요한 경우에만 자료 제공이 필요할 수 있다. 공개된 모든 종목에 다년도 원본/확정 정답/상세 해설이 존재한다고 보장하지 않는다. 예제·실기 공개 과제·공식 기출·복원·랜덤 모의고사는 수집 단계에서 구분한다. 검색결과의 ‘2026년 모의고사’를 실제2026년 정기시험 회차로 등록하지 않는다.

조사일: 2026-11-15 (Asia/Seoul). 범위는 **공식 자료·문제 출처 조사와 현재 구조 분석**이다. 시험 선택 화면, 신규 문제, 가져오기 기능, 일정·할인 계산은 구현하지 않았다. 첨부 마스터 문서는 조사 후보 목록으로 참고했으며 그 안의 즉시 구현 지시는 실행 범위로 확대하지 않았다.

## 결론과 준비 순서

두 번째 종목으로는 **PC정비사 2급의 자료 준비부터** 시작하기 좋다. ICQA에 2026년 4회 필기 HWP 게시물이 있고 현재 앱과 같은 단일선택 풀이 흐름을 활용할 수 있다. 단, 공개되어 있다는 사실과 재게시 가능 여부는 다르다. 게시물의 이용 안내 확인과 원본·최종 정답·해설 검수를 끝내야 문제 수록으로 넘어간다. 이는 개발 적합성 판단이며 개인의 자격증 취득 우선순위를 확정한 것은 아니다. [공식 게시물](https://www.icqa.or.kr/cn/board/dataroom/264)

그다음 후보는 네트워크관리사 1급·인터넷보안전문가 2급이다. 리눅스마스터 2급은 공식 출제범위를 이용한 자체 문제 작성 또는 이용 허가가 확인된 자료를 준비한다. GIS·정보처리·정보보안·CCNA는 아래 상태표의 보류 사항을 해결한 뒤 진행한다. 모든 종목에 기출 3~5년을 일괄 확보할 수 있다고 가정하지 않는다.

## 확인 상태를 읽는 방법

- **확인**: 해당 페이지에서 특정 내용이나 첨부 이름을 확인했다. 원문 문항·최종 정답·재게시 권한까지 모두 확인했다는 뜻은 아니다.
- **경로 확인**: 공식 기관/자료실 진입점을 찾았다. 해당 종목의 사용 가능한 문제 파일은 미확보다.
- **추가 확인**: 세부 페이지 추출 실패, 최신 기준 전문 미검토, 이용 허용 미확인 등 다음 작업이 남아 있다.
- **공식 링크 연결 / 허가 확인 후 수록 / 자체 제작**은 서로 다른 제공 방식이다. 링크를 찾았다는 이유로 문제 JSON을 만들지 않는다.

신규 수록 완료 문항은 이번 조사에서 **0개**다. 원본 파일을 대량 다운로드하거나 외부 사이트를 크롤링하지 않았다.

## 원본과 정답을 받기 전 준비할 목록

첫 후보 PC정비사 2급은 한 회차부터 아래 자료가 준비되어야 한다. 사용자에게 지금 파일 제공이나 기관 연락을 요구하는 단계는 아니다.

1. 공식 게시물 주소·회차·A/B형·적용 기준·첨부 파일 이름/해시.
2. 시험지 전체와 표·그림·정답표, 별도 최종 정답/정정 공지. 가답안은 상태를 분리한다.
3. 공개 서비스 수록 방식에 맞는 이용 허용 근거와 조건. 문제지·제3자 해설·이미지의 권리는 구분한다.
4. 문항별 원문 대조와 자체 해설의 근거·오답 보기 설명. 답 번호만 있는 자료는 상세 해설 완료로 세지 않는다.
5. 검수자가 확인한 문항만 시험에 포함하는 목록. 확보한 수/검수한 수/공개 가능한 수를 나눠 센다.

예전 자료의 OS·버전 기준은 당시 기준으로 보관한다. 최신 범위와 겹친다는 이유로 문장·정답을 임의로 현대화하지 않는다.

## 향후 입력 형식 초안

서버/DB를 새로 도입하지 않고 개발 원본 파일→검사→정적 자산 생성으로 시작할 수 있다. JSON을 기본 후보로 두고 CSV는 단순 객관식/표 형식 입력이 필요할 때 추가하는 편이 기존 구조와 맞다. 아직 아래 필드를 읽는 코드는 없다.

| 묶음 | 필드 후보 |
|---|---|
| 자격/기준 | `certificationId`, `level`, `stage`, `subjectId`, `standardVersion`, `validFrom`, `validTo` |
| 회차 | `paperId`, `year`, `round`, `form`, `questionCount`, `durationMinutes`, `passRule` |
| 문항 | 유지되는 `id`, `type`, `question`, `options`, `answer`, `explanation`, `images` |
| 출처 | `sourceUrl`, `sourceKind`(공식기출/공식예제/자체제작), 원문 번호, 원본 해시, `checkedAt` |
| 독립 검수 | `answerStatus`, `explanationStatus`, `rightsStatus`, `contentStatus`, 검수일/담당 기록 |

확인일 하나로 모든 검수가 끝났다고 표현하지 않는다. `draft → reviewed → published`는 출처·권한·정답·해설을 각각 통과해야 이동하는 상태로 제안한다. 데이터가 비어 있거나 미확인인 신규 시험은 출제 목록에서 제외한다. 기존 네트워크 자료를 이 규칙 도입과 동시에 삭제하는 파괴적 변경은 하지 않는다.

다중선택·단답·서술·실습 가이드는 현재 단일 정답 필드에 억지로 넣지 않는다. 지원하지 않는 유형은 가져오기 오류 또는 학습 가이드로 명확히 나눈다. 필기와 1차/2차는 같지 않으므로 `stage`는 화면에 보이는 이름과 별도의 안정적인 ID를 둔다.

## 나중에 구현을 시작한다면

1. PC정비사2급 한 회차의 원본·확정 정답·권한·자체 해설을 준비하고 검수한다.
2. 종목 컨텍스트와 규칙을 분리하고 네트워크의922개 ID/정답·기존 저장·기존 URL을 비교한다.
3. 두 시험을 선택하는 최소 화면과 종목별 문제 수/준비 중 상태를 제공한다. 공통 기능은 복사하지 않고 선택 종목을 주입한다.
4. 시험별 오답·산성비·복습·백업 격리, 구버전 가져오기, 잘못된 종목 ID 거부를 검증한다.
5. 나머지 종목은 확보/검수된 콘텐츠부터 추가한다. 과목별 과락·단계별 제한은 해당 종목 규칙 검증 후 제공한다.

이 순서는 구현 계획 제안이다. 이번 작업에서 위 단계를 실행하지 않았다. 일정 관리·지원금 계산·17종목 UI는 이번 조사 범위 밖이다.

## 한계와 다음 확인

출처는 공식 페이지의 검색 색인과 추출 가능한 본문을 이용해 확인했다. HWP/PDF 첨부를 내려받아 전 문항·정답·표·그림을 검수하지 않았다. 일부 Q-Net 페이지는 메뉴 틀만 추출되거나 접근 오류가 있어 최신 출제기준 전문·공지 내용은 미확인으로 남겼다. 정보보안2027 기준은 게시 제목 확인까지이며 첨부 전문은 읽지 않았다. 새 시험이 같은 문제를 반복 출제한다는 가설이나 지식 겹침 비율·예상 점수는 계산하지 않았다.

실제 이용자 후기/과제 테스트를 조사한 작업은 아니다. UI를 바꾸지 않아 새 화면 실기기 검증도 수행하지 않았다. 문의 발송·API 연결·모델 설치·Git·배포는 하지 않았다. 자료 후보 조사는 끝났으며 원문 검수와 실제 수록은 별도 작업이다.
