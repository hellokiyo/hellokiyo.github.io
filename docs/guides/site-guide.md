# 합격루틴 사용과 관리 안내

네트워크관리사 2급 필기 대비 정적 학습 사이트입니다. 최신 안내 기준은 2026-11-13이며, 개발·운영 문서는 [문서 진입점](../README.md)에서 읽을 수 있습니다.

## 먼저 공부할 것

2025년 3회차 이후 기출부터 풀고, 틀린 문제를 오답노트에서 다시 확인한 뒤 해당 핵심정리를 읽습니다. 이전 회차는 반복 패턴을 보충할 때 사용합니다. 산성비는 짧은 키워드 복습용입니다.

## 기능

- 기출: 2022~2026년 수록 회차와 연도/개정 필터, 최신 회차 바로가기. 원본 확보 대기 회차와 공식 정답 미확인 상태는 화면에서 구분합니다.
- 자체 연습: 72문항을 이용한 10문제 연습과 50문제·50분 실전. 공식 과목별 비율을 재현한 모의고사는 아닙니다.
- 오늘의 학습: 단서와 문제를 풀고 기억 평가에 따라 간격 복습을 예약합니다.
- 키워드 54개: 검색·분류·정답·암기 체크·문제 예시와 판별 근거.
- 명령어 87개와 핵심정리 12단원: 검색·읽음·서브넷 계산.
- 기능별 오답노트: 오늘의 학습·산성비·키워드·자체 연습·기출별 복습. 기존 출처 불명 기록은 이전 기록으로 보존합니다.
- 산성비: 90초 챌린지, 정답률·내 답·오답 목록, 모드별 한 판 최고점 배지. 누적 GP는 배지 조건이 아닙니다.
- 다음 공부 추천: 브라우저의 최근 활성 시간 기준. 작은 이유와 자료 비교 근거를 확인할 수 있습니다. 예상 성적을 계산하는 기능은 아닙니다.
- 공부 도우미: 오른쪽 아래 버튼으로 기능·기존 용어를 검색합니다. 열 때마다 초기화되며 외부 AI API를 사용하지 않습니다.
- 시험 자료: 파일 드롭·개인 보관·검토·게시용 ZIP. 파일을 넣었다고 자동 채점 문제가 생성되지는 않습니다.
- 14일 계획·시험일·테마·기록 내보내기/가져오기·PWA.

## 파일로 보기와 설치해서 보기

`index.html`을 직접 열어 일반 화면을 볼 수 있습니다. 파일 주소의 저장/복사는 브라우저별 차이가 있습니다. PWA 설치·Service Worker는 localhost 또는 HTTPS 주소에서 확인합니다.

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8000/`을 엽니다. 종료는 해당 터미널에서 Ctrl+C입니다. 파일 주소·localhost·공개 사이트는 기록 저장 공간이 다르므로 이전할 때 JSON 백업을 이용합니다.

## 기록 보관

설정에서 학습 기록을 JSON으로 내보내고 가져올 수 있습니다. 새 백업에는 게임 최고점과 누적 GP도 포함합니다. 구버전 파일에 게임 필드가 없으면 기존 게임 기록을 덮어쓰지 않습니다. 시험 자료 원본과 추천용 이용 시간·테마는 이 학습 JSON의 백업 범위와 다릅니다. 중요한 원본 파일은 별도로 보관하세요. 다른 기기와 자동 동기화하지 않습니다.

## 직접 올릴 때

Git 연결·커밋·푸시·배포는 사용자가 직접 관리합니다. `index.html`, `manifest.webmanifest`, `sw.js`, `README.md`, `docs/`, `assets/network/`, `materials/` 등 참조 파일과 폴더 구조를 함께 유지하세요. index만 올리면 동작하지 않습니다. 기존 프로젝트의 다른 자료도 임의로 삭제하지 않습니다.

변경 후 `node scripts/check-site.cjs`를 실행하고 [운영 절차](../operations.md)의 페이지별 수동 항목을 확인하세요. 페이지 제목이 보이는 것과 채점·복원·실기기·오프라인이 검증된 것은 다릅니다.
