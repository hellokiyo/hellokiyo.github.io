# 합격루틴 · 아주 쉬운 사용법

이곳은 시험을 연습하는 공부방이에요. 가입하지 않아도 쓸 수 있어요.

## 딱 세 가지만 해 봐요

1. **문제를 골라요.** 홈에서 ‘최신 기출 풀기’를 누르거나 ‘문제 풀이’에서 연도와 회차를 골라요. 짧게 하려면 ‘오늘의 학습’으로 5분만 해 봐요.
2. **답과 이유를 봐요.** 보기를 누르고 ‘정답 확인’을 눌러요. 어려우면 ‘핵심정리’의 그림과 설명을 봐요. 실전 연습은 제출한 뒤 답을 볼 수 있어요.
3. **틀린 것을 다시 풀어요.** ‘오답노트’를 열어요. ‘오늘의 학습’처럼 어디에서 틀렸는지도 골라 볼 수 있어요.

## 이 버튼은 무슨 뜻일까요?

| 버튼 | 뜻 |
|---|---|
| 모름 | 다시 연습하고 싶어요. |
| 헷갈림 | 아직 확실하지 않아요. 찍어서 맞혔을 때도 골라요. |
| 기억남 | 답과 이유를 알고 있어요. |
| 추가 학습 | 오늘의 학습 한 묶음이 끝난 뒤 더 풀어요. |
| 읽기 완료 | 핵심정리의 이 단원을 읽었다고 표시해요. |

오늘의 학습에서 틀린 답은 확인하는 순간 오답노트에 들어가요. 틀렸는데 기억남을 눌러도 없어지지 않아요. 나중에 맞히고 기억남을 고르면 오늘의 학습 목록에서 빠져요. 다른 기능의 오답은 따로 남을 수 있어요.

## 어디로 가면 될까요?

- **키워드 암기:** 짧은 단서를 보고 답을 떠올려요. ‘문제 예시’도 열어 보세요.
- **핵심정리:** 그림·화살표·비유로 개념을 보고, 아래 본문에서 자세히 읽어요. 휴대폰에서는 ‘목차’를 눌러 다른 단원을 골라요.
- **명령어 노트:** 명령어의 이름이나 하고 싶은 일로 찾아요. 여기에 적힌 명령은 읽는 설명이며 실제로 실행되지 않아요.
- **산성비:** 90초 동안 단서를 맞히는 게임이에요. 끝나면 ‘정답 목록’을 열어 내가 고른 답과 정답을 비교해요. 게임 점수는 시험 점수가 아니에요.
- **시험 자료:** PDF나 HWP 같은 원본을 보관해요. 파일을 넣는 것만으로 풀 수 있는 문제가 자동으로 만들어지지는 않아요.
- **설정:** 톱니바퀴를 눌러 시험 날짜·화면 색을 바꾸거나 기록 파일을 내보내요.
- **공부 도우미:** 기능과 용어를 찾는 검색이에요. 현재 자유 대화 AI는 연결되어 있지 않아요.

## 기록을 잃지 않으려면

기록은 지금 사용하는 브라우저에 있어요. 다른 기기·브라우저·주소에서는 다르게 보일 수 있어요. 소중한 기록은 **설정 → 학습 기록 내보내기**로 파일에 담아 두세요. 개인 자료 파일과 화면 색까지 전부 담기는 것은 아니에요.

기출의 확인 상태도 읽어 주세요. 일부 회차는 상세 해설이 부족하거나 공식 정답표 대조가 끝나지 않았어요.
