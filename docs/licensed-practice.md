# 공개 라이선스 보충 연습 (v32 · 2026-11-16)

## 추가한 자료와 이용 조건

Charles R. Severance의 *Introduction to Networking* (2015) 전자판 장별 연습문제 12개를 한국어로 번역·수정하고 해설을 추가했다.

- 저자 공식 사이트: https://www.net-intro.com/
- 원문 PDF: https://do1.dr-chuck.net/net-intro/EN_us/net-intro.pdf
- 허가 근거: PDF 실제 2쪽 Copyright Details에서 전자판 PDF/EPUB/HTML은 **CC BY 4.0**, 종이판은 CC BY-NC 4.0으로 구분한다. 이번에는 전자판을 사용했다.
- 이용 조건: https://creativecommons.org/licenses/by/4.0/ — 원저자 표시, 라이선스 링크, 변경 사실 표시를 유지한다.
- 변경: 한국어 번역, 보기 표현 수정, 해설 추가(합격루틴). 이 번역·수정 문항도 CC BY 4.0으로 제공한다. 이 조건은 해당 보충 문항에 적용되며 기존 기출 전체의 라이선스를 바꾸지 않는다.
- 원문 위치: 2.7 Q1/2/3/4/5/7, 5.5 Q1/3, 6.8 Q1/3, 8.8 Q1/2. 데이터에 실제 PDF 페이지 번호를 함께 기록했다.

원문이 공개되어 있다는 이유가 아니라 명시된 변경·재배포 허가를 근거로 사용했다. 저자의 동의·보증 또는 Cisco/국내 자격 시행기관의 검수를 뜻하지 않는다. 정답과 한국어 해설은 교재 설명을 근거로 작성했으며 공식 시험 정답표가 아니다.

## 사이트에서 이용하기

시험 선택 → 아래 시험 중 하나 → 문제 풀이 → **공개 연습 12문제 풀기**.

- CCNA
- 정보기기운용기능사
- 네트워크관리사 1급
- 인터넷보안전문가 2급
- 정보보안기사
- 정보보안산업기사

맞춤 연습의 문제 범위에서도 ‘공개 라이선스 연습’을 고를 수 있다. 공통 네트워크 기초의 12개 고유 문항을 6시험에 공유한다(저장용 ID는 총72개). 이를 72개 고유 문제나 6시험 기출 확보로 세지 않는다. 기존 자체 빠른 연습·시간 제한 연습은 기존 문제 수를 유지한다. 해당 시험의 기초 팩과 기출 팩을 바꾸지 않고 보충 문항을 전체 질문 목록에 더했다.

채점·북마크·같은 문제 반복·오늘의 학습·오답 복습에 연결된다. 실제 기출이 아니므로 연도/회차 목록에 넣지 않는다. 오답은 현재 기존 ‘자체 문제풀이’ 출처에 묶인다. 문항 안에서는 공개 자료의 번역·수정임을 별도 표시한다. 향후 공개 연습 전용 오답 분류를 만들지는 않았다.

## 내용 보완

2015년 교재를 최신 실제 시험처럼 표시하지 않는다. 공유 비밀키 문항은 ‘대칭키가 인터넷에 부적합’이라는 넓은 표현을 ‘비밀키의 안전한 사전 배포 문제’로 좁혔다. TLS가 실제 데이터에 대칭키를 사용하는 점을 해설에 추가했다. CSMA/CD에는 공유 매체·반이중 이더넷 조건을 덧붙였다. 교재의 위상·역사 자료 전체 또는 그림을 무분별하게 복제하지 않았다.

## 조사했지만 수록하지 않은 자료

- [KAIT 공식 문제공개](https://www.ihd.or.kr/guidequestion.do?curpage=1&exam_kind=LMF&search_flag=1): 소유권과 무단 이용 금지 안내가 있다. 다운로드 공개를 재사용 허가로 간주하지 않았다.
- [ICQA 이용약관](https://www.icqa.or.kr/cn/content/provision): 자료실 기출문제 등의 권리 소유 안내가 있다. 별도 재수록 허가가 확인된 것으로 기록하지 않았다.
- [정보기기운용기능사 Q-Net 공개문제](https://www.q-net.or.kr/cst006.do?artlSeq=5206296&brdId=Q006&code=1204&gSite=Q&id=cst00602): 게시물을 확인했으나 필기 기출로 혼동하거나 공개 사실만으로 변형 가능하다고 판단하지 않았다.
- [Q-Net 제140회부터 기술사 기출 공공누리 적용 공지](https://www.q-net.or.kr/cst006.do?artlSeq=5274124&brdId=Q006&gSite=Q&id=cst00602): 기존 시험 선택 목록과 다른 기술사 종목을 임의로 추가하지 않았다.

이번 조사로 다른 시험의 최근5년 기출이 확보된 것은 아니다. 차단을 피하는 경로나 접근 제한 우회, 다른 사이트에 올라온 동일 파일의 무단 재수록은 수행하지 않았다. 자료 자체의 공개 라이선스 조건을 충족하는 경로를 사용했다.

## 구현·검증·한계

- `assets/network/data/licensed-practice.js`: 수작업 번역·해설 원본과 저작자/허가/원문 위치. 생성 파일이 아니다.
- `app.js`: 기존 시험 Q 목록에 보충 문항을 조립한다. 기존 저장 키·문항 ID를 유지한다.
- `core.js`: 자체/공개 라이선스/기출 출처 필터를 분리한다.
- `quiz-page.js`: 시작 버튼·출처/라이선스 링크 표시. `daily-study.js`: 실제 기출로 표기하지 않는다.
- `index.html`, `sw.js`: 로딩 및 오프라인 목록, 워커 v32.0. 로그인·외부 기록 전송·키 관리·Git 작업 없음.
- `node scripts/check-site.cjs`: 정적 참조58개·전체JS구문·116테스트 통과. 새 테스트는 출처 분리, 번역·허가 정보 보존, 시작 버튼 채점 연결, 저장 왕복·북마크·오답·시험 간 격리를 검사한다.
- 브라우저 조작 도구가 이번 작업에서 제공되지 않아 실제 브라우저/모바일 화면·PWA 설치/오프라인 재생 검증은 미실행이다. 테스트는 Node VM과 도메인 함수에서 수행했으며 브라우저 검증으로 표현하지 않는다.
