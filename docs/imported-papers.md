총 69개 HWP를 시험·날짜로 묶어 교사용/학생용 중복을 제거한 30회차, 2,120문항이다. 제공된 기간을 그대로 표시하며, 없는 연도나 회차를 복제하지 않는다. 회차 번호를 추정하지 않고 시험 날짜로 구분한다.

## 사용법

시험 선택 → PC정비사 / 리눅스마스터 / 정보처리기사 → 문제 풀이 → 최신 회차 풀어보기. 아래 연도 선택에서 과거 시험을 고른다. 최신은 **수록 파일 중 최신**이며 현재 시행기관 최신 시험이라는 뜻이 아니다.

기출별 채점, 같은 회차 반복, 오답노트의 ‘기출문제’, 북마크, 맞춤 연습의 ‘수록된 기출’, 오늘의 학습 복습에 연결된다. 자체 기초 문제·키워드·산성비 콘텐츠가 이번 기출 전체를 설명하도록 자동 확장된 것은 아니다. 시간 제한 기초 연습은 기존 20문항이며 회차 연습은 원문 전체 50/80/100문항으로 시간 제한 없이 푼다.

## 원본과 생성 방식

- 원본: `docs/test/PC정비사2급/`, `docs/test/리눅스마스터2급/`, `docs/test/정보처리기사/`. 파일을 이동하거나 덮어쓰지 않는다.
- `python scripts/build-user-papers.py`: `scripts/hwp_reader.py`로 HWP5의 CFB·문단·그림 스트림만 읽는다. Python 표준 라이브러리만 필요하다. 매크로·OLE·문서 스크립트를 실행하지 않는다. 암호화/배포용 문서는 거절한다.
- 생성 데이터: `assets/network/data/exam-papers.js`, 그림: `assets/network/papers/imported/`. 데이터 파일을 직접 고치지 말고 생성 규칙을 수정해 재생성한다.
- 검사 원장: [회차별 추출 근거](../audits/user-papers-2026-11-16.json). 교사용 파일 SHA-256, 원본 경로, 문항 수, 그림 수, 해설 수, 학생용 본문·정답표 대조 결과를 기록한다.
- 원문 비트맵을 추출해 질문·보기의 ‘그림 1’ 등 번호와 연결한다. 그림이 들어간 보기의 순서는 보존한다. HWP 전체 지면의 글꼴/배치 복원기는 아니다. 형식 근거: [한컴 HWP5 공개 명세](https://cdn.hancom.com/link/docs/한글문서파일형식_5.0_revision1.3.pdf).

## 정답·해설 확인 수준

모든 문항에서 교사용 정답 표시, 교사용 정답표, 학생용 정답표를 대조하고 교사용/학생용 본문·그림의 일치도 검사한다. 시행기관 최신 정답을 새로 검수했다는 뜻이 아니다. 자료 출처인 전자문제집 CBT의 표시와 해설 작성자 표기는 제공 파일대로 보존한다.

제공 해설집 9개에서 상세 해설 840개를 연결했다. 해설집이 없는 1,280문항은 상세 해설 미제공을 알린다. 새 AI 해설을 생성한 것은 아니다. 오탈자가 있는 교사용 본문과 해설집의 질문은 번호 및 문구 유사도를 대조한다. 질문 내용을 코드로 실행하지 않는다.

리눅스마스터 2021-03-13 41번은 해설집에 확정답 3·4번 안내가 있다. 교사용에는 4번만 표시되어 있어 이 차이를 설명하고 두 답을 정답 처리한다. 복수 정답 규칙은 배포 문항 데이터에만 두며 사용자 백업에서 정답을 가져오지 않는다.

## 저장·오프라인·운영

기존 시험별 학습 저장 키와 네트워크 문항 ID를 유지한다. 회차 ID는 문항에 등록된 `paperId`로 검증해 다른 시험/알 수 없는 회차를 거절한다. 80·100문항을 50문항으로 잘라 저장하지 않는다. 원본 HWP는 다운로드 링크로 제공하며 서비스 워커의 선행 캐시에 넣지 않는다. 생성 문제·그림은 캐시에 포함한다. 실제 오프라인 이용은 새 워커 설치 완료 후 가능하다.

로그인·서버·AI API·키 관리·외부 기록 전송·Git 작업은 추가하지 않았다. 공개 배포는 사용자가 직접 관리하며 재배포 조건 확인도 별도다.

## 검증과 한계

`node scripts/check-site.cjs`: 정적 참조 57개·JS 구문·114개 테스트 통과. 추가 검증은 30회차 문항 번호/보기/그림 존재, 50·80·100문항 저장 왕복, 시험 간 기록 격리, 복수 정답 채점과 오답 연결이다. 브라우저 표시·조작 결과는 작업 일지에 별도로 기록한다. HWP 전 지면과 모든 그림의 육안 대조, 실제 휴대폰, 시행기관 정답 재검수 완료를 의미하지 않는다.
