# 실기 적합성 반복 검토 · 2026-11-25

## 결론과 평가의 경계

공개 복원 한 세트의 요구사항에 대응하는 내부 설명을 보완했다. 정보 충족도 환산은 22→93.5지만 **실제 시험 수행 점수는 미측정**이다. 정답을 먼저 읽은 비블라인드 대조이며, 공식 프로그램에서 80분 전체 시험을 치른 결과가 아니다. 따라서 사용자가 요청한 실제 수행 90점 달성을 입증한 것으로 처리하지 않는다.

기준선22는 확인된 실기 안내·공통 학습 설명에서 완전한 근거가 있는 항목만 센 보수적 감사값이다. 기존 필기 기출 전체를 사람이 시험 보듯 재풀이한 기준선이 아니므로 서비스 전체의 학습 효과·예상 점수로 해석하면 안 된다. 추가 검색에서 기존 show users는 VLAN 문제의 오답 보기였고 사용법 근거는 아니었다. SOA 개념은 있었지만 요구된 시간 필드와 GUI 대응은 부족했다. 필기 자료의 개별 단편으로 더 풀 수 있었을 가능성은 남는다.

## 공식 도구 실행 준비 · 다운로드 문제 해결 / 설치 차단

공식 공개 페이지를 먼저 읽고 같은 세션에서 정상 다운로드 링크를 요청해 설치 파일15,337,472바이트를 TEMP에 확보했다. 기본 환경 DNS 오류 후 허용된 네트워크 권한 확대로 받은 것이며 로그인·접근 제어를 우회하지 않았다. 이전 다운로드 실패 상태는 이 후속 결과로 갱신한다.

읽기 전용 MSI 검사에서 DHCP/DNS/IIS/사용자/서비스 등의 모형 실행 파일이 포함됨을 확인했다. 서명은 NotSigned로 관찰됐으며 공식 출처라는 사실과 별개로 기록한다. 파일의 SHA-256과 출처는 `audits/practical-2026-11-25/official-program-preflight.json`에 있다. 프로그램 원본은 저장소에 재배포하지 않았다.

사용자가 설치·실행 검증을 명시적으로 허용한 뒤 설치 마법사를 열었다. 설치 로그의 `VSDFXAvailable` 조건 false와 .NET3.5 요구를 확인했다. 공식 프로그램 본체 실행·시험 과제 수행은 아직 안 했다.

반환된 설치 창을 Computer Use로 선택하자 `product policy blocks this app: msiexec.exe`로 차단됐다. 다른 도구/무인 설치로 우회하지 않았다. 설치 완료나 약관 동의·UAC 승인을 관찰하지 못했다. 사용자가 수동 설치를 완료해야 공식 도구의 후속 과제 수행 검증을 진행할 수 있다. 이를 실제 수행 점수의 미검증 이유로 남긴다.

## 설치 완료 후 시작 화면 확인
사용자 설치 완료 응답 뒤 설치된 공식 ICQA 예제와 .NET3.5 설치 표시를 확인했다. 공식 시작 화면 버전2.0,20251203을 읽었다. 설치 대기 상태는 해결됐다. 다만 대상 앱이 조작 도구보다 높은 Windows integrity로 실행되어 접근성은 창만 반환했고 시험 선택 클릭도 시각적 변화가 없었다. 사용자에게 임시 이름과 네트워크관리사2급 선택 후 문제 화면 진입을 요청했다. 공식 과제 조작/제출/채점은 아직 미수행이다.

## 공식 예제 문제 화면 진입·1번 관찰
사용자가 문제 화면을 열었다. 화면은2026년 sample 예제이며 번호 버튼은15개다. 앞선 비공식 복원18문항과 다른 세트이므로 같은 배점표를 자동 적용하지 않는다. 1번은 스위치와 단말 간1Gbps 결선으로, 문제의 작업 주의사항이Straight=T568B를 지정한다. 내부 안내로 B-B와8가닥 결선을 도출할 수 있지만 실물 압착을 수행하지 않았으므로 점수를 부여하지 않았다. 자체 따라하기에 일반 A-A 가능 여부보다 지정 표준을 우선한다는 문장을 명확히 보완했다. 전체 문항 원문·사용자 이름은 감사 데이터에 복제하지 않았다. `official-example-run.json`에 실제 수행과 정보 대응을 분리해 기록한다. 높은 Windows integrity로 자동 클릭은 여전히 불가하여 사용자에게2번 열기를 요청했다.
