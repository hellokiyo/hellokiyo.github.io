# 시험별 학습 설계 · v29

> v31 변경: PC정비사·리눅스마스터·정보처리기사에 사용자 제공 실제 기출30회차2120문항을 추가했다. 아래 기초 팩 설명과 별도로 [최신 기출 수록량](imported-papers.md)을 확인한다.

기존 IIFE 화면에 시험별 데이터를 주입한다. 문서 재탐색으로 시험을 바꾸므로 진행 중 타이머와 화면 상태가 섞이지 않는다. 서버·프레임워크·API 키는 추가하지 않았다.

## 데이터와 범위

- `assets/network/data/exam-practice.js`: 11개 분야의 자체 기초 개념 110개를 16개 시험에 배정. 시험별 20문항, 네트워크관리사1급과 공간정보융합산업기사는 30문항. 시험별 ID를 부여한 총340문항이며 340개의 독립 원문 기출이라는 뜻은 아니다. 해설·키워드 예시·개념 정리·14일 계획을 함께 만든다.
- `ExamCatalog.ready`는 실제 기출 수록 여부, `learningReady`는 학습 기능 이용 가능 여부다.
- 기술 참고 링크는 분야의 배경 자료다. 모든 문항의 공식 시험 출제 근거나 공식 검수 증거가 아니다. 현재 기초 문제의 일부 보기 난이도는 실제 시험보다 낮다.
- 실제 회차 자료는 `EXAM_PAPER_SOURCES`에서 확인한다. 출처 메타데이터를 채점 문제처럼 가장하지 않는다. 다년도 원문 파싱·정답 대조·그림 보완은 남은 작업이다.
- 명령이 없는 분야의 노트는 실행 명령이 아닌 용어·표현이라고 표시한다. 핵심정리에 네트워크 전용 그림/서브넷 계산기를 주입하지 않는다.

## 상태와 호환

네트워크는 기존 `network-notes:v1`, `network-keyword-rain:v1`, `network-notes-materials:v1`을 유지한다. 확장 시험은 `cert-study:{id}:v1`, `cert-game:{id}:v1`, IndexedDB `cert-materials:{id}:v1`이다. 테마는 공통이다. 자료 저장소는 `StudyMaterialsStore.forExam(id)`가 분리한다.

설정 백업에 certificationId를 넣고 다른 시험의 백업은 확인 대화상자를 열기 전에 거부한다. 식별자가 없는 구버전은 네트워크 백업으로 해석한다. 문제·키워드 정제는 기존 StudyCore/ReviewCore/WrongNotebook을 재사용한다.

## 화면과 규칙

앱 조립부가 D/B/P/A와 게임 저장 키를 선택하고 각 모듈에 주입한다. 확장 시험의 시간 제한 연습은 보유 문항수와 같은 분(20/30분)의 서비스 연습이며 공식 시험 시간이 아니다. 공식 시험 형식·과락 규칙을 구현했다는 뜻도 아니다. 게임 GP와 연습 점수는 별개다.

StudyCoach는 확장 시험에서도 활성 시간에 따라 문제풀이/핵심정리/산성비를 제안한다. 확장 시험은 `cert-coach:{id}:v1`로 최근7일을 분리하며 네트워크 전용22%/88점 근거표를 표시하지 않는다. 추천 이용 시간은 기존 학습 JSON 백업에 포함되지 않는다. 공부 도우미의 용어 검색은 선택된 시험 데이터만 사용한다. 파일 보관은 시험별 DB, 공개 네트워크 파일은 다른 공부방에 노출하지 않는다. 파일이 자동 채점 문제로 변환되는 기능은 없다.

## 검증 및 인수인계

`node scripts/check-site.cjs` 실행. 확장 문항의 ID 중복·4개 보기·정답과 키워드 대응·해설 존재·잘못된 ID 제거·저장 왕복, 다른 시험 백업 거부를 확인한다. v28의 초기 검증은 [초기 JSON](../audits/exam-learning-v28.json), v29의 비교 검증은 [비교 보고서](exam-parity-2026-11-16.md)과 개발 일지에 남긴다. 기존 네트워크 문제/정답 기준 해시를 유지한다.

문항을 늘리려면 해당 분야 banks에 질문/정답/오답보기3개/이유/선택적 명령을 추가한다. 특정 시험에만 필요한 분야는 별도 bank로 만들고 profiles에 연결한다. 기출을 추가할 때에는 출처·권리·회차·정답 확정 상태·그림을 먼저 검수하고 자체 문제와 별도 어댑터로 넣는다.

학습 연습: PC와 리눅스에서 각각 오답을 만든 뒤 시험을 바꿔도 목록이 섞이지 않는지 확인하고, 데이터 주입과 저장 키 분리가 서로 다른 책임인 이유를 설명해 본다.

홈·사용법은 네트워크와 확장 시험이 같은 렌더러를 사용한다. 시험별로 제목/기출 여부/수량만 바꾸며 시험일 설정·이어가기·복습 현황·목표 체크가 모두 제공된다. 확장 계획은 해당 시험의 실제 단원 경로로 이동하고, 일자별 추천은 제공되는20/30분 기초 연습을 구분한다.
